# Tags and Keywords

## Describing a Resource's Subject

Keywords are words or phrases that describe a resource's subject. Tags are labels attached to resources so related items can be grouped. Both help describe content, but their usefulness depends on choosing terms that match the resource and the reader's needs.

A title identifies a particular page, while subject terms can connect several pages. For example, two pages with different [[resource-description/descriptive-titles|Descriptive Titles]] might share the subject “soccer photography” because they address different parts of that topic.

## Choosing Useful Terms

### A Soccer Photograph Example

For a photograph showing Jordanian supporters holding flags before a match, useful subject terms might include:

- Soccer
- Jordan supporters
- Stadium
- Flags

A player's name would be misleading if that player does not appear in the photograph. Adding popular but unrelated terms makes the description less trustworthy.

Start with the main subject, then add a few details that distinguish the resource. A short, accurate set is more useful than a long list of loosely related words.

## Keeping Labels Consistent

A controlled vocabulary is an agreed set of preferred terms. For a small collection, this could be a simple list that records which labels to use. If the preferred term is “soccer,” record “football” as an alternative term so contributors understand the choice. An alternative term only improves searching if the system records or supports it.

Consistency also involves spelling and capitalization. Using “Jordan supporters” on one record and “Jordan Supporters” on another can create unnecessary variation.

## Reviewing Subject Terms

Read the resource before assigning labels. Then ask whether each term describes something actually present. Review spelling, remove duplicates, and compare similar records.

These checks are part of [[resource-description/metadata-quality|Metadata Quality]]. For photographs, combine subject terms with the fuller context explained in [[resource-description/describing-images|Describing Images]].
