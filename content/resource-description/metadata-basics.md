# Metadata Basics

## What Is Metadata?

Metadata is information that describes a resource. The resource might be a photograph, a document, a video, or a webpage. Its metadata helps someone understand what it contains before opening it. Dublin Core provides common descriptive elements, including title, creator, subject, description, and format.

The resource and its description serve different purposes. A photograph shows a scene, while its description can explain who created it and what the scene represents. A useful description gives enough context to help a reader decide whether the resource meets their needs.

## A Practical Example

### Describing a Soccer Photograph

Imagine organizing a collection of soccer photographs. A file called IMG_2048.jpg gives little information about its content. An illustrative metadata record could include:

- *Title:* Jordan Supporters Before a Soccer Match
- *Creator:* Name of the photographer
- *Subject:* Soccer, Jordan, supporters
- *Description:* Supporters holding Jordanian flags in the stadium stands before kickoff.
- *Format:* JPEG image

These details answer different questions. The title identifies the photograph, the creator records responsibility, and the description explains its visible content. Unknown details should be checked rather than guessed.

## Making Metadata Useful

Descriptions should match the actual resource. A clear title works together with meaningful keywords; repeating vague words adds little value. See [[resource-description/descriptive-titles|Descriptive Titles]] for naming guidance and [[resource-description/tags-and-keywords|Tags and Keywords]] for choosing consistent search terms.

> Practical reminder: Describe a resource so another person can understand why it matters.
