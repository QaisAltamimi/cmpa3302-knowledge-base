# Metadata Quality

## What Makes a Description Useful?

Metadata quality depends on whether a description helps someone identify, understand, and find the correct resource. A record can contain many fields and still be unhelpful if those fields are inaccurate or unclear. Quality therefore involves checking the meaning of the information, not simply counting completed fields.

The elements explained in [[resource-description/metadata-basics|Metadata Basics]] provide a starting point. Choose the fields that serve the collection's purpose, and check their values against the actual resource.

## Reviewing a Soccer Photograph

### Accuracy and Completeness

Consider a stadium photograph showing spectators holding Jordanian flags. A useful description can mention the pitch, stands, and visible flags. However, the flags alone do not establish the opponent, match date, or stadium name. Those details require confirmation from the photographer or another reliable record.

Completeness means including the information needed for the task. For a personal photograph collection, the creator, subject, and a useful description may matter more than recording every possible technical detail.

## A Practical Review Checklist

1. *Accuracy:* Does each statement match the resource or a verified source?
2. *Clarity:* Do the title and description explain the subject?
3. *Consistency:* Are spelling and labels used consistently across similar records?
4. *Relevance:* Do the keywords describe meaningful features?
5. *Functionality:* Do the image and internal links open correctly?

Check [[resource-description/descriptive-titles|Descriptive Titles]] when a label is vague. Review [[resource-description/tags-and-keywords|Tags and Keywords]] when similar resources use conflicting subject terms.

## Maintaining Quality Over Time

Review descriptions when new information becomes available. Correct mistakes without inventing missing details, and explain significant changes in commit messages. For images, follow [[resource-description/describing-images|Describing Images]] to check the caption, alternative text, and creator information.

> A useful record tells readers what is known and makes uncertainty clear.
